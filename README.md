# Hi, I'm Rob 👋

I build real systems from scratch in Python, and explain every idea so a curious 12-year-old can follow.

## 📚 [From scratch in Python](https://robcox2910.github.io/)

Seventeen projects, each a working system you can run and poke at, with plain-English docs and everyday analogies for every concept. Standard library only (PyLLM adds NumPy), built test-first.

| Project | Build your own… |

| [PyDB](https://robcox2910.github.io/pydb/) | SQL database: joins, B-tree indexes, a query planner, transactions |
| [PyNet](https://robcox2910.github.io/pynet/) | network stack: DNS, TCP, HTTP and WebSockets over raw sockets |
| [PyGit](https://robcox2910.github.io/pygit/) | Git: hashing, trees, commits, branches and diffs |
| [PyLLM](https://robcox2910.github.io/pyllm/) | GPT: autograd, attention, a Transformer and training |

…plus key-value, document, graph, time-series, vector and column-family databases, cryptography, a web server, a search engine, a message queue, and [PyStack](https://robcox2910.github.io/pystack/), which joins them all together.
